## Non-negotiables

1. **UI**: Follow [IPTRUST_design.md](../IPTRUST_design.md) — base `#FFFFFF`, primary `#0A1626`, accent `#A88B52`, 8px grid, Tailwind token mapping.
2. **Evidence**: No material claim in user-facing answers without a citation to stored evidence.
3. **Implementation log**: After each step in [implementation-plan.mdc](../implementation-plan.mdc), append `Done` and a two-line summary.
